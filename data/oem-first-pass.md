# OEM First Pass

这是一份保守版首轮对照表，只保留我能在公开资料里直接核到的号码，或者只能确认到平台代号的项目。

- `verified`: 公共资料里能直接看到部件号，且和产品名称基本一致
- `platform match only`: 只能确认平台/车型代号，不能确认到唯一 OEM 号
- `needs confirmation`: 公开资料不足，不能可靠确认

## 备注

- 传动轴比转向臂、羊角更容易找到公开部件号，但也常常要区分前轴、中桥、后桥、短轴和中间支撑。
- 转向臂和转向节通常还要看左右件、孔距、花键、轴头和前桥代号，单靠名字很难直接定 OEM。
- 这份表适合先放进客服/销售内部查号；如果你要，我下一步可以把它整理成更适合网站后台或 Excel 导入的 CSV/JSON。
